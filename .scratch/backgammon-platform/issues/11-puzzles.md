# 11: Puzzle player and curated set

**What to build:** The Puzzles pillar: checker-play puzzles ("find the best play for this roll") and cube-decision puzzles ("double, take, or pass?") answered on the board, graded by equity tolerance (correct if within 0.02 of the engine's best), with the full equity table revealed after answering. Puzzles carry themes (priming, blitzing, holding game, bear-off, cube handling); missed puzzles enter a retry queue; solved/missed progress persists. Ships with a bundled curated set (at least ~25 positions across the themes) generated by an engine self-play mining script (positions with one clear, instructive best play — no copyrighted book positions) and included as app data; the mining script stays in the repo for future set expansion.

**Blocked by:** 04 (engine worker), 06 (cube and match play), 07 (persistence).

**Status:** ready-for-agent

- [ ] Both puzzle types playable end to end: attempt → grade → equity table reveal → next
- [ ] Near-equal alternatives (within 0.02) grade as correct; the reveal shows why
- [ ] Retry queue resurfaces missed puzzles; per-theme progress persists across reloads
- [ ] Curated set is bundled, themed, and every puzzle's stored best answer matches a fresh engine evaluation (validation test)
